# Patch canon check (G2)

Checked 2026-10-10 against search-result snippets of the Dungeon Crawler Carl fan
wiki. The wiki pages themselves return HTTP 402 to the fetch tool, so every
"verified" below means "a snippet of the wiki page says so", not "I read the page".
The wiki is community-maintained, not official. Its own Battle Rattle patch table
lists "+1 all base stats" on patches whose own pages omit it (not relevant to art).

Status key: V = verified by wiki snippet, C = contradicts `patches.md`,
U = unverified (no source found), P = partly verified.

## Consequences for the contract

- The Bomb canon anchor is **black blackwork on white**, not a fire palette.
  Needs an operator decision (asked at G2).
- The Back patch stays dropped. Nothing found supports a separate patch.
- No claim about the Earth plume, Book Burner appearance or the Scavenger's
  glow was verified. Prompts treat them as optional flavour, not canon.
